# School Drive

## Системаи идоракунӣ ва мубодилаи файлҳои таълимӣ

### 1. Маълумот дар бораи лоиҳа

**School Drive** — вебсистемае мебошад, ки барои нигоҳдорӣ, идоракунӣ ва мубодилаи файлҳо ва маводи таълимӣ дар муассисаҳои таълимӣ пешбинӣ шудааст.

Мақсади асосии лоиҳа рақамикунонии раванди нигоҳдорӣ ва дастрасӣ ба маводи таълимӣ, осон намудани мубодилаи ҳуҷҷатҳо ва ташкили муҳити ягонаи рақамӣ барои омӯзгорон ва донишҷӯён мебошад.

### 2. Мақсади лоиҳа

- Таъмини муҳити ягона барои нигоҳдории файлҳо.
- Осон намудани мубодилаи маводи таълимӣ.
- Ташкили файлҳо ва папкаҳо.
- Таъмини дастрасии истифодабарандагон мувофиқи ҳуқуқҳои онҳо.
- Кам кардани истифодаи ҳуҷҷатҳои коғазӣ.

### 3. Истифодабарандагони система

- **Administrator** — идоракунии система ва истифодабарандагон.
- **Teacher** — илова ва идоракунии маводи таълимӣ.
- **Student** — дастрасӣ ба файлҳо ва маводи таълимӣ.

### 4. Имкониятҳои асосии система

- Идоракунии истифодабарандагон.
- Бақайдгирӣ ва воридшавӣ ба система.
- Боркунӣ ва зеркашии файлҳо.
- Сохтан ва идоракунии папкаҳо.
- Ҷустуҷӯи файлҳо.
- Мубодилаи файлҳо.
- Идоракунии ҳуқуқҳои дастрасӣ.

### 5. Технологияҳо

Технологияҳои истифодашаванда дар раванди таҳия муайян ва дар ин қисм илова карда мешаванд.
