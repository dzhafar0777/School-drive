# School Drive

### Системаи идоракунӣ ва мубодилаи маводи таълимӣ

## 1. Маълумот дар бораи лоиҳа

**School Drive** — вебсистемаест, ки барои идоракунӣ, нигоҳдорӣ ва мубодилаи маводи таълимӣ байни омӯзгорон ва донишҷӯён дар муассисаҳои таълимӣ пешбинӣ шудааст.

Система имконият медиҳад, ки омӯзгорон маводи таълимӣ, лексияҳо, китобҳои электронӣ, презентатсияҳо, супоришҳо ва дигар ҳуҷҷатҳои таълимиро ҷойгир намоянд. Донишҷӯён бошанд, метавонанд ба ин мавод дастрасӣ пайдо карда, онҳоро тамошо ё зеркашӣ кунанд.

Лоиҳа бо мақсади рақамикунонии муҳити таълимӣ, осон намудани дастрасӣ ба дониш ва беҳтар намудани мубодилаи иттилоот таҳия карда мешавад.

## 2. Мақсади лоиҳа

Мақсади асосии School Drive ташкили платформаи ягонаи рақамӣ барои нигоҳдорӣ ва мубодилаи маводи таълимӣ мебошад.

Вазифаҳои асосӣ:

- Рақамикунонии раванди мубодилаи маводи таълимӣ.
- Таъмини дастрасии осон ба лексияҳо ва китобҳои электронӣ.
- Ташкили китобхонаи электронии таълимӣ.
- Осон намудани кори омӯзгорон бо маводи таълимӣ.
- Фароҳам овардани имконияти омӯзиши мустақилонаи донишҷӯён.
- Таъмини идоракунии мутамаркази маводи таълимӣ.

## 3. Истифодабарандагони система

Система се гурӯҳи асосии истифодабарандагонро дар бар мегирад.

### 3.1. Administrator (Администратор)

- Идоракунии истифодабарандагон.
- Илова, таҳрир ва нест кардани ҳисобҳо.
- Идоракунии фанҳо ва категорияҳо.
- Назорати маводи ҷойгиршуда.
- Идоракунии ҳуқуқҳои дастрасӣ.

### 3.2. Teacher (Омӯзгор)

- Илова кардани маводи таълимӣ.
- Бор кардани лексияҳо ва презентатсияҳо.
- Ҷойгир кардани супоришҳо.
- Таҳрир ва нест кардани маводи худ.
- Гурӯҳбандии мавод аз рӯйи фанҳо.
- Мубодилаи маводи таълимӣ бо донишҷӯён.

### 3.3. Student (Донишҷӯ)

- Дидани рӯйхати фанҳо.
- Ҷустуҷӯи маводи таълимӣ.
- Дастрасӣ ба лексияҳо ва китобҳои электронӣ.
- Тамошо ва зеркашии файлҳо.
- Дидани супоришҳои таълимӣ.

## 4. Имкониятҳои асосии система

- **Authentication:** бақайдгирӣ ва воридшавӣ ба система.
- **User Management:** идоракунии истифодабарандагон.
- **Educational Materials:** илова ва идоракунии маводи таълимӣ.
- **Subject Management:** идоракунии фанҳои таълимӣ.
- **File Management:** боркунӣ, тамошо ва зеркашии файлҳо.
- **Search:** ҷустуҷӯи маводи таълимӣ.
- **Categories:** гурӯҳбандии мавод аз рӯйи фан ва навъи ҳуҷҷат.
- **Access Control:** идоракунии ҳуқуқҳои дастрасӣ.
