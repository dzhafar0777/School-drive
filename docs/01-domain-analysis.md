# 01. Таҳлили соҳаи предметӣ (Domain Analysis)

## 1. Муқаддима

School Drive системаи вебиест, ки барои идоракунӣ, нигоҳдорӣ ва мубодилаи маводи таълимӣ байни омӯзгорон ва донишҷӯён пешбинӣ шудааст.

Дар муассисаҳои таълимӣ ҳар рӯз миқдори зиёди маводи таълимӣ, аз ҷумла лексияҳо, китобҳои электронӣ, презентатсияҳо, супоришҳо ва дигар ҳуҷҷатҳо истифода мешаванд.

Нигоҳдорӣ ва мубодилаи чунин мавод тавассути усулҳои анъанавӣ метавонад мушкилоти муайянро ба вуҷуд орад. Аз ин рӯ, зарурати ташкили системаи ягонаи рақамӣ ба миён меояд.

School Drive барои ҳалли ин масъалаҳо ва беҳтар намудани дастрасӣ ба захираҳои таълимӣ таҳия карда мешавад.

## 2. Тавсифи соҳаи предметӣ

Соҳаи предметии система раванди идоракунӣ ва мубодилаи маводи таълимиро дар муассисаҳои таълимӣ фаро мегирад.

Система байни се гурӯҳи асосии истифодабарандагон робита барқарор мекунад:

- Администратор — идоракунандаи умумии система.
- Омӯзгор — таъминкунандаи маводи таълимӣ.
- Донишҷӯ — истифодабарандаи маводи таълимӣ.

Маводи таълимӣ метавонад дорои навъҳои гуногун бошад:

- Лексияҳо.
- Китобҳои электронӣ.
- Презентатсияҳо.
- Супоришҳои мустақилона.
- Дастурҳои методӣ.
- Ҳуҷҷатҳои иловагии таълимӣ.

## 3. Мушкилоти мавҷуда

Дар раванди анъанавии мубодилаи маводи таълимӣ мушкилоти зерин ба вуҷуд омада метавонанд:

1. Пароканда нигоҳ доштани файлҳо дар дастгоҳҳо ва платформаҳои гуногун.
2. Душвор будани ҷустуҷӯи маводи зарурӣ.
3. Мураккаб будани мубодилаи ҳуҷҷатҳо байни омӯзгорон ва донишҷӯён.
4. Набудани низоми ягонаи гурӯҳбандии мавод.
5. Эҳтимоли гум шудани ҳуҷҷатҳо.
6. Маҳдуд будани назорати дастрасӣ ба маводи таълимӣ.

## 4. Мақсади таҳияи система

Мақсади асосӣ ташкили платформаи ягонаи рақамӣ мебошад, ки тавассути он омӯзгорон метавонанд маводи таълимиро ҷойгир ва идора кунанд, донишҷӯён бошанд, ба ин мавод дастрасӣ пайдо намоянд.

### 4.1. Вазифаҳои асосӣ

- Автоматикунонии раванди мубодилаи маводи таълимӣ.
- Таъмини нигоҳдории мутамаркази файлҳо.
- Ташкили китобхонаи электронии таълимӣ.
- Таъмини ҷустуҷӯ ва гурӯҳбандии мавод.
- Идоракунии истифодабарандагон ва ҳуқуқҳои онҳо.
- Баланд бардоштани самаранокии дастрасӣ ба дониш.

## 5. Истифодабарандагони система

### 5.1. Администратор (Administrator)

Администратор ҳуқуқҳои васеи идоракунии системаро дорад.

Вазифаҳо:

- Илова ва таҳрири истифодабарандагон.
- Идоракунии ҳисобҳои омӯзгорон ва донишҷӯён.
- Идоракунии фанҳо ва категорияҳо.
- Назорати маводи таълимӣ.
- Идоракунии ҳуқуқҳои дастрасӣ.

### 5.2. Омӯзгор (Teacher)

Омӯзгор барои омода ва ҷойгир кардани маводи таълимӣ масъул мебошад.

Вазифаҳо:

- Илова кардани маводи таълимӣ.
- Бор кардани файлҳо.
- Таҳрири маълумоти мавод.
- Нест кардани маводи худ.
- Гурӯҳбандии мавод аз рӯйи фанҳо.
- Ҷойгир кардани супоришҳои таълимӣ.

### 5.3. Донишҷӯ (Student)

Донишҷӯ истифодабарандаи маводи таълимии система мебошад.

Вазифаҳо:

- Дидани фанҳои таълимӣ.
- Ҷустуҷӯи маводи зарурӣ.
- Тамошои ҳуҷҷатҳои таълимӣ.
- Зеркашии файлҳо.
- Дастрасӣ ба супоришҳои таълимӣ.

## 6. Равандҳои асосии корӣ (Business Processes)

### 6.1. Раванди воридшавӣ ба система

1. Истифодабаранда саҳифаи воридшавиро мекушояд.
2. Номи корбар ё почтаи электронӣ ва рамзи махфиро ворид мекунад.
3. Система маълумоти воридшударо месанҷад.
4. Дар сурати дуруст будани маълумот истифодабаранда ба система ворид мешавад.
5. Система интерфейси мувофиқи нақши истифодабарандаро нишон медиҳад.

### 6.2. Раванди ҷойгир кардани маводи таълимӣ

1. Омӯзгор ба система ворид мешавад.
2. Қисмати илова кардани маводро интихоб мекунад.
3. Файлро бор мекунад.
4. Номи мавод, тавсиф ва фанро муайян мекунад.
5. Система маълумотро месанҷад.
6. Мавод дар система сабт мешавад.
7. Донишҷӯёни дорои ҳуқуқи дастрасӣ метавонанд маводро истифода баранд.

### 6.3. Раванди дастрасии донишҷӯ ба мавод

1. Донишҷӯ ба система ворид мешавад.
2. Фан ё категорияро интихоб мекунад.
3. Рӯйхати маводи дастрасро мебинад.
4. Маводи заруриро интихоб мекунад.
5. Файлро тамошо ё зеркашӣ мекунад.

### 6.4. Раванди идоракунии система

1. Администратор ба система ворид мешавад.
2. Қисмати идоракуниро мекушояд.
3. Истифодабарандагон, фанҳо ё категорияҳоро идора мекунад.
4. Тағйиротро сабт мекунад.
5. Система маълумоти навшударо нигоҳ медорад.

## 7. Қоидаҳои бизнес (Business Rules)

1. Ҳар як истифодабаранда бояд ҳисоби алоҳида дошта бошад.
2. Ҳар як истифодабаранда бояд нақши муайян дошта бошад.
3. Танҳо истифодабарандагони дорои ҳуқуқи мувофиқ метавонанд маводи таълимиро илова кунанд.
4. Омӯзгор метавонад маводи ба ӯ тааллуқдоштаро идора кунад.
5. Донишҷӯ танҳо ба маводи барои ӯ иҷозатдодашуда дастрасӣ дорад.
6. Ҳар як маводи таълимӣ бояд ба фан ё категорияи мувофиқ мансуб бошад.
7. Система бояд маълумоти асосии файлро нигоҳ дорад.
8. Файлҳои боршаванда бояд аз рӯйи формат ва андозаи иҷозатдодашуда санҷида шаванд.
9. Администратор ҳуқуқи идоракунии умумии системаро дорад.
10. Дастрасӣ ба амалҳои система бояд мувофиқи нақши истифодабаранда маҳдуд карда шавад.

## 8. Объектҳои асосии соҳаи предметӣ

| Объект | Тавсиф |
|---|---|
| User | Истифодабарандаи система |
| Role | Нақши истифодабаранда |
| Teacher | Омӯзгор |
| Student | Донишҷӯ |
| Subject | Фанни таълимӣ |
| Category | Категорияи мавод |
| Material | Маводи таълимӣ |
| File | Файли боршуда |
| Assignment | Супориши таълимӣ |

## 9. Натиҷаи интизоршаванда

Дар натиҷаи таҳияи School Drive системаи ягонаи рақамӣ ба вуҷуд меояд, ки имкониятҳои зеринро фароҳам меорад:

- Нигоҳдории мутамаркази маводи таълимӣ.
- Дастрасии қулай барои омӯзгорон ва донишҷӯён.
- Ҷустуҷӯ ва гурӯҳбандии мавод.
- Идоракунии истифодабарандагон.
- Мубодилаи самараноки ҳуҷҷатҳои таълимӣ.
- Беҳтар намудани раванди омӯзиш.

## 10. Хулоса

Дар ин ҳуҷҷат соҳаи предметии School Drive, мушкилоти мавҷуда, мақсад, вазифаҳо, гурӯҳҳои истифодабарандагон, равандҳои асосии корӣ ва қоидаҳои бизнес муайян карда шуданд.

Натиҷаҳои таҳлил ҳамчун асос барои таҳияи талаботи техникӣ, моделсозии UML ва тарҳрезии базаи маълумот истифода мешаванд.
