# 03. Талаботи кӯтоҳи техникӣ (Short Specification)

## 1. Маълумоти умумӣ

**Номи лоиҳа:** School Drive

**Навъи система:** Вебсистемаи таълимӣ.

**Соҳаи истифода:** Муассисаҳои таълимӣ.

**Истифодабарандагони асосӣ:** Administrator, Teacher, Student.

School Drive системаест, ки барои нигоҳдорӣ, идоракунӣ ва мубодилаи маводи таълимӣ байни омӯзгорон ва донишҷӯён пешбинӣ шудааст.

## 2. Мақсади система

Мақсади асосии система ташкили муҳити ягонаи рақамӣ барои дастрасӣ ба маводи таълимӣ мебошад.

Система бояд имконият диҳад, ки омӯзгорон маводи таълимиро ҷойгир кунанд ва донишҷӯён онҳоро тамошо ва зеркашӣ намоянд.

## 3. Талаботи функсионалӣ (Functional Requirements)

### FR-01. Бақайдгирӣ ва воридшавӣ

Система бояд имконияти воридшавии истифодабарандагонро тавассути маълумоти шахсӣ таъмин намояд.

### FR-02. Идоракунии истифодабарандагон

Администратор бояд имконияти илова, таҳрир, фаъол ва ғайрифаъол кардани ҳисобҳои истифодабарандагонро дошта бошад.

### FR-03. Идоракунии нақшҳо

Система бояд се нақши асосиро дастгирӣ намояд:
- Administrator
- Teacher
- Student

### FR-04. Идоракунии фанҳо

Администратор бояд имконияти илова, таҳрир ва нест кардани фанҳои таълимиро дошта бошад.

### FR-05. Илова кардани маводи таълимӣ

Омӯзгор бояд имконияти бор кардани файл ва илова намудани маълумоти он, аз ҷумла ном, тавсиф ва фанро дошта бошад.

### FR-06. Таҳрир ва нест кардани мавод

Омӯзгор бояд маводи ба ӯ тааллуқдоштаро таҳрир ё нест карда тавонад.

### FR-07. Дидани маводи таълимӣ

Донишҷӯ бояд рӯйхати маводи барои ӯ дастрасро дида тавонад.

### FR-08. Зеркашии файлҳо

Система бояд имконияти зеркашии файлҳои таълимиро таъмин намояд.

### FR-09. Ҷустуҷӯи мавод

Система бояд ҷустуҷӯи маводро аз рӯйи ном, фан ва категория таъмин намояд.

### FR-10. Гурӯҳбандии мавод

Маводи таълимӣ бояд аз рӯйи фан ва навъи ҳуҷҷат гурӯҳбандӣ карда шавад.

### FR-11. Идоракунии супоришҳо

Омӯзгор бояд имконияти ҷойгир кардани супоришҳои таълимиро дошта бошад.

### FR-12. Назорати дастрасӣ

Система бояд ҳуқуқҳои истифодабарандагонро мувофиқи нақши онҳо назорат намояд.

## 4. Талаботи ғайрифунксионалӣ (Non-Functional Requirements)

### NFR-01. Амният

Маълумоти истифодабарандагон бояд муҳофизат карда шавад. Рамзҳои махфӣ бояд дар шакли хэш нигоҳ дошта шаванд.

### NFR-02. Иҷроиш

Система бояд дархостҳои истифодабарандагонро бо вақти муносиб коркард намояд.

### NFR-03. Қулайӣ

Интерфейси система бояд одӣ, фаҳмо ва барои истифодабарандагон қулай бошад.

### NFR-04. Мутобиқат

Система бояд дар браузерҳои муосир кор кунад.

### NFR-05. Эътимоднокӣ

Система бояд маълумотро дуруст нигоҳ дошта, аз гум шудани файлҳо пешгирӣ намояд.

### NFR-06. Васеъшавӣ

Сохтори система бояд имконияти илова кардани функсияҳои навро дошта бошад.

### NFR-07. Нигоҳдорӣ

Код бояд сохтори фаҳмо ва нигоҳдории осон дошта бошад.

## 6. Сенарияҳои асосии истифода (Use Case Scenarios)

### UC-01. Воридшавӣ ба система

**Иштирокчӣ:** Administrator, Teacher, Student.

**Қадамҳо:**
1. Истифодабаранда саҳифаи воридшавиро мекушояд.
2. Маълумоти воридшавиро пур мекунад.
3. Система маълумотро месанҷад.
4. Истифодабаранда ба панели мувофиқ равона карда мешавад.

### UC-02. Бор кардани маводи таълимӣ

**Иштирокчӣ:** Teacher.

**Қадамҳо:**
1. Омӯзгор ба система ворид мешавад.
2. Қисмати илова кардани маводро мекушояд.
3. Файлро интихоб мекунад.
4. Маълумоти маводро пур мекунад.
5. Маълумотро сабт мекунад.
6. Система маводи навро нигоҳ медорад.

### UC-03. Зеркашии маводи таълимӣ

**Иштирокчӣ:** Student.

**Қадамҳо:**
1. Донишҷӯ ба система ворид мешавад.
2. Фанро интихоб мекунад.
3. Маводи заруриро меёбад.
4. Тугмаи зеркаширо пахш мекунад.
5. Файл ба дастгоҳи донишҷӯ зеркашӣ мешавад.

### UC-04. Идоракунии истифодабарандагон

**Иштирокчӣ:** Administrator.

**Қадамҳо:**
1. Администратор ба панели идоракунӣ ворид мешавад.
2. Қисмати истифодабарандагонро мекушояд.
3. Истифодабарандаро интихоб мекунад.
4. Маълумотро илова ё таҳрир мекунад.
5. Тағйиротро сабт мекунад.

## 7. Талаботи амниятӣ

- Дастрасӣ ба система тавассути Authentication таъмин карда шавад.
- Ҳуқуқҳо тавассути Role-Based Access Control (RBAC) идора карда шаванд.
- Рамзҳои махфӣ дар шакли хэш нигоҳ дошта шаванд.
- Файлҳои боршуда санҷида шаванд.
- Истифодабаранда набояд ба маълумоти ғайри иҷозатдодашуда дастрасӣ дошта бошад.
- Амалиёти муҳим бояд аз тарафи сервер санҷида шаванд.

## 8. Маҳдудиятҳои система

- Дастрасӣ ба функсияҳо аз нақши истифодабаранда вобаста мебошад.
- Андоза ва формати файлҳои боршаванда бояд маҳдуд карда шавад.
- Истифодабаранда барои истифодаи системаи онлайн бояд пайвасти шабакавӣ дошта бошад.
- Дастрасӣ ба маводи маҳдудшуда бояд бо иҷозат таъмин карда шавад.

## 9. Меъёрҳои қабул (Acceptance Criteria)

Система вақте ба талаботи асосӣ ҷавобгӯ ҳисобида мешавад, ки:

1. Истифодабарандагон тавонанд ба система ворид шаванд.
2. Нақшҳо ва ҳуқуқҳои дастрасӣ дуруст кор кунанд.
3. Администратор тавонад истифодабарандагонро идора кунад.
4. Омӯзгор тавонад маводи таълимиро бор кунад.
5. Донишҷӯ тавонад маводи иҷозатдодашударо тамошо ва зеркашӣ кунад.
6. Ҷустуҷӯи маводи таълимӣ дуруст кор кунад.
7. Система дастрасии ғайриқонуниро маҳдуд кунад.

## 10. Хулоса

Дар ин ҳуҷҷат талаботи функсионалӣ, ғайрифунксионалӣ, нақшҳо, сенарияҳои истифода ва талаботи амниятии School Drive муайян карда шуданд.

Ин талаботҳо ҳамчун асос барои моделсозии UML, тарҳрезии базаи маълумот ва таҳияи архитектураи система истифода мешаванд.
