# UI Kit — School Drive

**Мақсад:** системаи ягонаи визуалӣ барои платформаи вебии нигоҳдорӣ, ҷустуҷӯ ва мубодилаи маводи таълимӣ.  
**Версия:** 1.0  
**Ҳолат:** тарҳрезии мақсаднок  
**Услуби асосӣ:** мавзӯи торики School Drive бо акцентҳои бунафш ва кабуд.

## 1. Принсипҳои интерфейс

School Drive маъмур, омӯзгорон ва донишҷӯёнро муттаҳид мекунад. Объекти асосии интерфейс маводи таълимӣ мебошад: корбар бояд маводро зуд пайдо кунад, фан, навъи файл, муаллиф ва амалҳои дастрасро фаҳмад.

- **Маводи таълимӣ дар маркази диққат:** ном, фан, навъи ҳуҷҷат, муаллиф ва санаи навсозӣ.
- **Навигатсияи содда:** бахшҳои асосӣ тавассути навигатсияи доимӣ дастрас мебошанд.
- **Ҷудокунии нақшҳо:** Administrator, Teacher ва Student менюҳо ва ҳуқуқҳои гуногун доранд.
- **Ҳолатҳои фаҳмо:** ҳолат тавассути матн ва нишондиҳандаи визуалӣ нишон дода мешавад.
- **Истифодаи маҳдуди эффектҳои визуалӣ:** градиентҳо танҳо барои акцент истифода мешаванд, на барои ҳар як элемент.
- **Мутобиқшавӣ:** сенарияҳои асосӣ дар телефон, планшет ва компютер дастрас мебошанд.
- **Дастрасӣ:** нишонаҳои намоёни майдонҳо, фокуси клавиатура, контрасти кофӣ ва паёмҳои хатои фаҳмо.

## 2. Сетка ва мутобиқшавии интерфейс

### Desktop — 1440 px

- Масоҳати асосии мундариҷа: то 1200 px.
- Сеткаи асосӣ: 12 сутун.
- Навигатсияи паҳлӯӣ: тақрибан 240 px.
- Фосила байни карточкаҳо: 20–24 px.

### Tablet — 768 px

- Навигатсияи паҳлӯӣ ба менюи компактӣ табдил меёбад.
- Карточкаҳои мавод ҳангоми мавҷуд будани паҳнои кофӣ дар 2 сутун ҷойгир мешаванд.
- Филтрҳои ҷустуҷӯ ба панели алоҳида гузаронида мешаванд.

### Mobile — 390 px

- Мундариҷа дар як сутун ҷойгир мешавад.
- Амалҳои асосӣ бе ҳаракати уфуқӣ дастрас мебошанд.
- Ҷадвалҳо ба карточкаҳо табдил меёбанд ё дар минтақаи ҳаракатшавандаи уфуқӣ ҷойгир мешаванд.
- Форматҳои боркунӣ ва ирсоли файлҳо барои истифодаи сенсорӣ мувофиқ карда мешаванд.

### Градиентҳо

- Акценти асосӣ: бунафш `#7C5CFF` → кабуд `#00D4FF`.
- Градиенти иловагӣ танҳо барои hero-блок ё равшании ороишӣ иҷозат дода мешавад.
- Градиентро барои матнҳои дароз, нишонаҳои хурд ва ҳолатҳое, ки контрасти паст доранд, истифода набаред.

### Дастрасӣ

Ҳадафи асосӣ WCAG 2.2 AA мебошад:

- на камтар аз 4.5:1 барои матни оддӣ;
- на камтар аз 3:1 барои матни калон ва сарҳадҳои графикии муҳим.

Контраст бояд барои ҳар як ҷуфти воқеии рангҳо, аз ҷумла hover, focus ва disabled, чен карда шавад. Ранг набояд ягона воситаи нишон додани ҳолат бошад.

## 5. Компонентҳо ва ҳолатҳои онҳо

### Button

Навъҳо: Primary, Secondary, Outline, Danger, Ghost.  
Ҳолатҳо: Default, Hover, Focus, Disabled, Loading.

- Баландии амали асосӣ: 44–48 px.
- Матни тугма бояд амалро ифода кунад: «Боркунии мавод», «Создани супориш», «Ирсоли кор».
- Амалҳои хатарнок бояд тасдиқи возеҳ талаб кунанд.

### Input / Search / Select

Ҳолатҳо: Default, Focus, Error, Disabled.

- Ҳар як майдон бояд нишонаи намоён дошта бошад.
- Placeholder нишонаи Label-ро иваз намекунад.
- Хато бояд бо шарҳи матнӣ ҳамроҳ бошад.
- Майдони ҷустуҷӯ ҳангоми мавҷуд будани функсия бояд тугмаи равшани тозакуниро дошта бошад.

### Material Card

Майдонҳои тавсияшаванда:

- номи мавод;
- фан;
- категория ё навъи файл;
- омӯзгор / муаллиф;
- санаи нашр ё навсозӣ;
- амали дастрас: кушодан ё зеркашӣ.

Рейтинг, шумораи зеркашиҳо ё ҳаҷми файлро, агар ин маълумот дар додаҳо мавҷуд набошад, нишон надиҳед.

### File Upload

Компонент дорои минтақаи интихоби файл, форматҳои иҷозатдодашуда ва маҳдудияти ҳаҷм, нишондиҳандаи боркунӣ, натиҷа ва хатогӣ мебошад.

- Маҳдудиятҳо бояд ба конфигуратсияи сервер мувофиқат кунанд.
- Агар функсияи drag-and-drop амалӣ нашуда бошад, онро ҳамчун имконияти мавҷуда нишон надиҳед.

### Badge / Status

| Ҳолат | Нишона | Вазифа |
|---|---|---|
| `ACTIVE` | Фаъол | объекти дастрас, агар ҳолат дар модел мавҷуд бошад |
| `DRAFT` | Лоиҳа | маводи нотамом, агар дастгирӣ карда шавад |
| `SUBMITTED` | Ирсол шудааст | кори донишҷӯ ирсол шудааст |
| `REVIEWED` | Санҷида шудааст | кор аз назар гузаронида шудааст |
| `ACCEPTED` | Қабул шудааст | кор қабул шудааст |
| `REJECTED` | Рад шудааст | кор рад шудааст |
| `ERROR` | Хатогӣ | амалиёт номуваффақ анҷом ёфтааст |

Ҷадвал нишонаҳои тавсияшавандаи UI-ро муайян мекунад. Пеш аз истифодаи қиматҳои кодӣ, онҳо бояд бо enum ва ҳолатҳои воқеии БД муқоиса карда шаванд.

### Modal / Dialog

Барои тасдиқи ҳазф ё дигар амалҳои барқарорнашаванда истифода мешавад.

Диалог бояд:

- натиҷаи амалро шарҳ диҳад;
- амали асосиро нишон диҳад;
- имконияти баромадан ё бекор карданро пешниҳод кунад.

### Empty State

Ҳангоми набудани мавод ё супоришҳо, шарҳи фаҳмо ва амали дастрасро нишон медиҳад, агар он барои нақши ҷорӣ иҷозат дода шуда бошад.

## 8. Иконкаҳо ва маводи визуалӣ

- Як маҷмӯи ягонаи иконкаҳои outline истифода шавад.
- Иконкаҳои PDF, DOCX, PPTX ва дигар навъҳои файл фарқ кунанд, аммо нишонаи матнии навъи файл нигоҳ дошта шавад.
- Тасвирҳо ва иллюстрацияҳо бояд ба маориф, ҳуҷҷатҳо ва китобхонаи рақамӣ мувофиқ бошанд.
- Маълумоти шахсии донишҷӯёнро дар макетҳои демонстративӣ ҷойгир накунед.
- Барои ҳолатҳои холӣ иллюстрацияҳои содда истифода шаванд, бе аз ҳад зиёд пур кардани интерфейс.
