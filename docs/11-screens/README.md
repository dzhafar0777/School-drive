# School Drive

**School Drive** — веб-платформа барои нигоҳдорӣ, ҷустуҷӯ, нашр ва мубодилаи маводи таълимӣ байни маъмурон, омӯзгорон ва донишҷӯён.

> **Ҳолати лоиҳа:** дар марҳилаи таҳия қарор дорад. Функсияҳо ва сенарияҳои тавсифшуда метавонанд ҳолати мақсадноки системаро инъикос кунанд ва на ҳамаашон ҳоло амалӣ шуда бошанд.

## Дар бораи лоиҳа

School Drive барои ташкил ва муттаҳид намудани маводи таълимӣ дар як фазои ягона кӯмак мекунад. Омӯзгорон метавонанд мавод ва супоришҳоро ҷойгир кунанд, донишҷӯён маводҳоро пайдо намуда, корҳои иҷрошударо ирсол кунанд ва маъмурият бошад, корбарон ва мундариҷаи платформаро идора намояд.

## Имкониятҳои асосӣ

- **Китобхонаи маводи таълимӣ:** нигоҳдорӣ, намоиш, ҷустуҷӯ ва ташкили файлҳо.
- **Фаъолияти омӯзгор:** нашри мавод, сохтани супоришҳо ва дидани корҳои ирсолшуда.
- **Фаъолияти донишҷӯ:** ҷустуҷӯи маводи таълимӣ, гирифтани супоришҳо ва ирсоли корҳои иҷрошуда.
- **Идоракунӣ:** идоракунии корбарон, мундариҷа ва платформа.
- **Амният:** санҷиши додаҳои воридшаванда, назорати дастрасӣ аз рӯйи нақшҳо ва намоиши бехатари мундариҷаи корбарон.

## Нақшҳои корбарон

| Нақш | Имкониятҳо |
|---|---|
| Администратор | Идоракунии корбарон, маводҳо ва танзимоти системавӣ |
| Омӯзгор | Нашри мавод, сохтани супоришҳо ва санҷиши корҳои донишҷӯён |
| Донишҷӯ | Намоиш ва ҷустуҷӯи маводҳо, гирифтани супоришҳо ва ирсоли корҳои иҷрошуда |

## Ҳуҷҷатгузорӣ

Ҳуҷҷатҳои лоиҳа дар каталоги `docs/` ҷойгир шудаанд.

| Бахш | Тавсиф |
|---|---|
| [`docs/10-screens`](docs/10-screens/) | UI Kit ва экранҳои асосии платформа |
| [`docs/11-screens`](docs/11-screens/) | Иллюстрацияҳои ҳолатҳои интерфейс, тасдиқҳо, хатогиҳои санҷиши маълумот ва сенарияҳои амниятӣ |

Маводҳои бахшҳои экранҳо иллюстрацияҳои тарҳрезӣ мебошанд. Онҳо худ аз худ амалӣ шудани функсияҳо ё бомуваффақият гузаштани тестҳоро тасдиқ намекунанд.

## Технологияҳо

Стекҳои технологӣ ҳангоми рушди лоиҳа муайян ва такмил дода мешаванд. Татбиқи воқеии ҷориро бояд бевосита аз рӯйи коди манбаъ ва конфигуратсияи репозиторий санҷид.

## Сохтори лоиҳа

```text
School-drive/
├── assets/              # CSS, JavaScript, тасвирҳо ва дигар захираҳои интерфейс
├── config/              # Конфигуратсияи барнома
├── database/            # Схемаи SQL ва файлҳои пойгоҳи додаҳо
├── docs/                # Ҳуҷҷатгузорӣ ва маводи UI
│   ├── 10-screens/
│   └── 11-screens/
├── admin.php            # Қисми маъмурӣ (агар дар версияи ҷорӣ истифода шавад)
├── instructor.php       # Бахши омӯзгор (агар истифода шавад)
├── student.php          # Бахши донишҷӯ (агар истифода шавад)
└── README.md
```

> Сохтори мазкур ҳамчун намуна пешниҳод шудааст ва бояд бо файлҳои воқеии репозиторий мувофиқ карда шавад.

## Амният ва сенарияҳои UX

Дар ҳуҷҷатҳои тарҳрезии лоиҳа сенарияҳои зерин баррасӣ мешаванд:

- тасдиқи ҳазфи маводҳо;
- ҳолатҳои боркунии файл ва хатогиҳои боркунӣ;
- хатогиҳои санҷиши маълумот дар шаклҳо (form validation);
- намоиши бехатари мундариҷаи корбарон (муҳофизат аз XSS);
- манъи дастрасӣ ба функсияҳо бе ҳуқуқҳои мувофиқ;
- ирсоли супориши иҷрошуда аз ҷониби донишҷӯ.

## Нақшаи рушди лоиҳа

- [ ] Мувофиқ намудани сохтори лоиҳа бо меъмории мақсадноки School Drive.
- [ ] Санҷиш ва ягонакунии схемаи пойгоҳи додаҳо.
- [ ] Амалӣ намудани аутентификатсия ва авторизатсия аз рӯйи нақшҳо.
- [ ] Амалӣ намудани каталог ва ҷустуҷӯи маводи таълимӣ.
- [ ] Амалӣ намудани идоракунии супоришҳо ва ирсоли корҳои донишҷӯён.
- [ ] Илова намудани воситаҳои маъмурӣ.
- [ ] Гузаронидани тестҳои функсионалӣ ва амниятӣ.
- [ ] Омода намудани ҳуҷҷатҳо оид ба ҷойгиркунӣ ва ба кор даровардани система.

## Иштирок дар таҳияи лоиҳа

Пешниҳодҳо, гузоришҳо оид ба хатогиҳо ва идеяҳои беҳбудӣ истиқбол карда мешаванд. Пеш аз ворид намудани тағйирот ба функсионалият, тавсия дода мешавад, ки бо ҳуҷҷатҳои дар `docs/` ҷойгиршуда шинос шуда, татбиқи ҷории лоиҳа санҷида шавад.

## Литсензия

Литсензияи лоиҳа ҳоло муайян карда нашудааст. Истифода, паҳнкунӣ ва тағйир додани код бо шартҳои литсензия танзим карда мешаванд, агар он ба репозиторий илова карда шавад.
